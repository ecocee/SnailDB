## 🚀 Quick Start (Copy & Paste)

```bash
# 1. Install dependencies
npm install

# 2. Build TypeScript
npm run build

# 3. Start SNAILDB server (in another terminal)
npm start

# 4. Run examples (back in first terminal)
# Run all examples
ts-node examples/test-all.ts

# Or run individual example
ts-node examples/src/01-ai-search.ts
```
