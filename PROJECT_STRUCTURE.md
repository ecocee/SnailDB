## File Descriptions

### Core Source Files

#### `src/index.ts` (20 lines)
**Purpose**: Public API entry point  
**Exports**: SnailDB class, all types, version utilities  
**Usage**: `import { SnailDB, IDocument } from 'snaildb'`

#### `src/snaildb.ts` (340+ lines)
**Purpose**: Core database implementation  
**Contains**:
- CRUD operations (insert, get, update, delete)
- Query engine with operators
- File I/O and persistence
- Utility methods (count, stats, export, import)

#### `src/types.ts` (65 lines)
**Purpose**: Type definitions and interfaces  
**Defines**:
- `IDocument` - Document structure
- `IOperationResponse<T>` - Response wrapper
- `ISuccessResponse<T>` - Success response
- `IErrorResponse` - Error response
- `IQueryResult` - Query result
- `IDatabaseStats` - Database statistics

#### `src/version.ts` (35 lines)
**Purpose**: Version management  
**Exports**: VERSION, VERSION_NAME, getVersion(), printVersion()

## Maintenance Notes

### Regular Updates
- Update `src/version.ts` for version changes
- Update `docs/` for API changes
- Update `package.json` for dependency changes

### Before Release
1. Update version in `src/version.ts`
2. Run: `npm test`
3. Run: `npm run lint`
4. Run: `npm run build`
5. Update `docs/` if needed
6. Update `CHANGELOG.md` (future)

### Adding Features
1. Write code in `src/`
2. Add types in `src/types.ts`
3. Write tests in `tests/`
4. Update `docs/API.md`
5. Update `examples/`
